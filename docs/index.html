ASCII Profile Generator

A Python-based image-to-ASCII generator for customizable static and animated ASCII art, with exports including SVG, PNG, JPEG, and GIF.

View on GitHub

What is this?

The ASCII Profile Generator is an open-source Python tool that converts images and photos into customizable ASCII art. Whether you need a static profile picture or an animated SVG for your GitHub README, this tool generates text art based on user configuration.

Export ASCII art as script-free animated SVG, PNG, JPEG, or GIF.

Key Features

Export Formats

Natively export your creations as scalable SVG, standard PNG and JPEG, or fully animated GIF files.

Animations

Supports 10 animation modes: Row Reveal, Column Reveal, Diagonal Reveal, Iris Aperture, Circular Reveal, Fade In, Twinkle, Sparkle Wave, Flag Wave, and Instant. Flag Wave is available through the Additional -> Flag menu. SVG exports retain animation without relying on JavaScript.

GitHub Profile Preset

Includes a dedicated GitHub preset that automatically sets the dimensions to 100×50 characters, transparent backgrounds, and standard scaling for developers building a GitHub README.

Color Customization

Derive cell colors from the original source image, force classic Light or Dark terminal themes, design custom color palettes, or generate dynamic Flag motifs.

Quick Start

You only need Python 3 installed. The setup script automatically creates a virtual environment and installs Pillow (the only dependency).

macOS / Linux

python3 setup.py
python3 ascii_generator.py sample.png

Windows

py setup.py
py ascii_generator.py sample.png

Frequently Asked Questions (FAQ)

How do I convert an image to ASCII art?

Run the ascii_generator.py script and provide your target image as an argument (e.g., python ascii_generator.py photo.jpg). The interactive CLI will guide you through choosing colors, size, animations, and the final export format.

Which image inputs are supported?

The generator supports any image format recognized by the Python Pillow library (including PNG, JPEG, WebP, BMP, and GIF).

Can I create ASCII art for a GitHub README?

Yes. The tool includes a built-in "GitHub Profile Preset" accessible right when you launch it. This sets the dimensions to a clean 100×50 grid, forces a transparent background to respect viewer system themes, and recommends SVG.

Can I export ASCII art as SVG?

Yes, SVG is natively supported and is the recommended format. SVGs scale without blurring and support built-in animations without requiring external JavaScript.

Does it work offline?

Yes. The entire conversion process relies on the local Python Pillow imaging library. No data is sent to any external server.

Can I customize the ASCII dimensions and character ramp?

Yes. The tool provides options to set custom dimensions, character cell sizes, and ASCII density ramps.

What dependency does the generator use?

Pillow is the project's required Python dependency.
