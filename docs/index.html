Key Features

Export Formats

Natively export your creations as scalable SVG, standard PNG and JPEG, or fully animated GIF files.

Animations

Supports 10 animation modes including Row Reveal, Twinkle, Sparkle Wave, and Flag Wave. SVG exports retain animation natively, though some platforms like GitHub may sanitize and restrict SVG animation.

Color Customization

Derive cell colors from the original source image, force classic Light or Dark terminal themes, design custom color palettes, or generate dynamic Flag motifs.

GitHub Profile Preset

The built-in GitHub Profile Preset automatically configures practical defaults for GitHub README and profile artwork.

  • Transparent background to match any system theme
  • 100×50 dimension sizing
  • Twinkle animation
  • SVG format (use GIF if GitHub restricts SVG animation)

Quick Start

You only need Python 3 installed. The setup script automatically creates a virtual environment and installs Pillow.

macOS / Linux 
python3 setup.py
python3 ascii_generator.py sample.png
Windows 
py setup.py
py ascii_generator.py sample.png

Frequently Asked Questions

How do I convert an image to ASCII art?
Run the ascii_generator.py script and provide your target image as an argument (e.g., python ascii_generator.py photo.jpg). The interactive CLI will guide you through choosing colors, size, animations, and the final export format.
Which image inputs are supported?
The generator supports any image format recognized by the Python Pillow library (including PNG, JPEG, WebP, BMP, and GIF).
Can I export ASCII art as SVG?
Yes, SVG is natively supported and is the recommended format. SVGs scale without blurring and support built-in animations without requiring external JavaScript. However, note that some platforms (like GitHub READMEs) strictly sanitize SVGs, which may strip animations. If your SVG doesn't animate on GitHub, export as GIF instead.
Does it work offline?
Yes. The entire conversion process relies on the local Python Pillow imaging library. No data is sent to any external server.
